### About this repo

The source of the portfolio: React 19, TypeScript, Tailwind CSS, and Framer Motion on Vite, with the Overworld in three.js on WebGL2. Every sound is synthesized live with Web Audio; there are no audio files.

```sh
npm install
npm run dev      # local server
npm test         # vitest
npm run deploy   # build and publish to GitHub Pages
```

The project's vocabulary lives in [CONTEXT.md](CONTEXT.md) and its design decisions in [docs/adr](docs/adr).
